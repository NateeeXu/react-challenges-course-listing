# Select Courses

Add course selection to the existing course schedule. Clicking a course card
should select it, and clicking the same card again should unselect it. Users
must be able to select any number of courses. Selected cards should be clearly
different from unselected cards, with a visible selected indicator.

Keep the existing term filter and course data. Selections should stay in place
when the user switches between Fall, Winter, and Spring. Store the selected
course IDs in React state; this task does not require saving them to Firebase.
Make the cards usable by keyboard as well as mouse, and keep the existing
responsive layout.
