# Display a List of Courses
Create a React application using TypeScript that displays my Fall 2026 courses.
Group the courses by subject, such as Computer Science and Electrical Engineering.
Each course card should display:

- Course number
- Course name
- Meeting time
- Location

Create a reusable CourseCard component.
Store the course information in an array and use map() to display the course cards.
Use App.css to create a clean and responsive layout. Display multiple cards in a row on larger screens and one card per row on smaller screens.
