# Weekly timetable

Add a Weekly timetable view inside Course plan alongside the existing List view.

- Start with the current catalog term and allow switching between Fall, Winter, and Spring inside the timetable.
- Show selected courses from that term in a Monday–Friday grid. Place each block according to its start time and duration.
- Show courses with no meeting time separately and explain when a term has no selected courses.
- Allow horizontal scrolling on small screens and reuse the existing meeting-time parser.
