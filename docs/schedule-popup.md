# Schedule Pop-up

Add a Course plan button beside the term selector, on the right when space
allows. Clicking it opens a pop-up listing all currently selected courses,
including courses from other terms. Show each course's number, title, term,
and meeting time. Use TBA when the meeting time is empty.

If no courses are selected, explain that the plan is empty and that clicking
course cards selects them. Include a Close button. Clicking outside the
pop-up should close it, while clicking its contents should keep it open.
Support Escape and keyboard focus. Closing the pop-up must not change course
selections. Keep the existing card styling and responsive layout.
